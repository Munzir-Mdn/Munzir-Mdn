# Cybersecurity Parallax Portfolio

Portfolio satu halaman menggunakan HTML, CSS dan JavaScript tanpa framework.

## Cara guna

1. Extract fail ZIP.
2. Buka folder `cyber_parallax_portfolio`.
3. Double-click `index.html`.
4. Untuk edit kandungan:
   - Struktur/kandungan: `index.html`
   - Rekaan: `style.css`
   - Animasi/parallax: `script.js`

## Ciri utama

- Responsive navigation
- CSS glassmorphism
- Parallax layers menggunakan JavaScript
- Scroll reveal animation
- Reduced-motion accessibility support
- GitHub dan LinkedIn buttons
- Tanpa build tools atau dependency JavaScript

## Nota

Font Google digunakan melalui `@import`, jadi browser memerlukan internet untuk memuatkan font tersebut. Jika tiada internet, browser akan fallback kepada font sistem.
